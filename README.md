# OpsMate

Runbook, log ve küme durumu üzerinden soru yanıtlayan bir operasyon asistanı.

Bu depo, DevOps ve yapay zekâ mühendisliğini uçtan uca öğrenmek için
yürüttüğüm 27 haftalık çalışmanın ürünüdür. Her fazın sonunda projeye
çalışan yeni bir parça eklenir.

## Öğrenilen teknolojiler

- **Temel:** Linux, Bash, Git, Python, SQL
- **DevOps:** Docker, GitHub Actions, Terraform, AWS, Kubernetes, Helm, Argo CD
- **Gözlemlenebilirlik:** Prometheus, Grafana, Loki, OpenTelemetry
- **Yapay zekâ:** PyTorch, LLM'ler, RAG, vektör veritabanları, LangChain
- **Arayüz:** TypeScript, Next.js

## Depo yapısı

- `docs/` — mimari notlar ve kararlar
- `notes/` — haftalık öğrenme notları
